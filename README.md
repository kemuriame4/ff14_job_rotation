# FF14 循环训练器

一个面向《最终幻想 14》战斗职业的 **技能循环训练与对比分析** 桌面工具。通过全局按键监听记录你的实际操作，与预设的标准循环/期望时间轴逐项比对，输出评分、时间偏差、冷却与连击问题，帮助打磨起手与循环。

- 界面：PySide6（Qt Widgets）
- 按键捕获：pynput（全局监听 + 应用内按键）
- 平台：Windows
- 数据：XIVAPI v2 + 中文数据挖掘仓库，覆盖 22 个战斗职业、1000+ 技能

***

## 功能一览

### 训练页

- 12 列 × 4 行游戏风格热键栏，支持点击技能施放、全局按键捕获。
- 训练设置：统计时长（5–1800 秒，含 30/60/120/180 快捷预设）、判定容差（默认 500ms）、全局监听开关。
- 3 秒倒计时后开始记录，实时显示已用时间与进度。
- 技能状态反馈：
  - **不可用置灰**：职业状态不满足（量谱/buff/跳舞限制等）。
  - **金色高亮**：标准循环中的下一步。
  - **金光强化**：技能已由 buff/连击强化。
  - **蓝色高亮**：连击可延续（如瀑泻/风车 → 喷泉/落刃雨，隐性 30 秒窗口，期间使用其他技能不打断）。
- 复唱遮罩：圆形扇形倒计时，**统一按秒显示**（90s 显示 `90`、120s 显示 `120`）。
- 充能技能：右下角显示当前可用层数；一层正在恢复时仍显示该层的回复倒计时，层数耗尽时显示最早恢复时间。
- 舞者专属：随机舞步序列、幻扇 0–4、伶俐数值、舞步期间的动作替换与可用限制。

### 键位映射页

- 拖拽调整热键栏位置，从技能池拖入空栏位。
- 双击栏位改键，右键清除热键/换色/重命名/移出栏位。
- 「自动分配热键」：按栏位顺序分配数字键（第 1 行 1–0，后续行叠加 Ctrl/Alt/Shift）。
- 热键属于栏位，拖拽图标不会改变栏位热键；重复键位会提示冲突。

### 标准循环页

- 逐步编辑标准循环（技能、类型、期望时间）。
- 期望时间自动推算：GCD 技能按当前 GCD 推进；能力技不占 GCD，按 0.65s 织入间隔插入；同一技能重复时受自身复唱限制。
- 可设置循环长度、GCD、是否循环重复；关闭重复时只比较一轮。
- 支持短 GCD 技能（如舞者舞步 1.5s），可在技能数据中单独配置 `gcd_time`。

### 分析报告页

- 综合评分与等级、顺序准确率、时间准确率。
- 标准/实际双泳道时间轴对比与播放头。
- 逐项差异表：缺失、多余、顺序错误、偏早/偏晚及偏差值。
- 问题统计：冷却冲突、GCD 冲突、连击中断、状态不足施放。
- 威力与 PPS 对比（单体威力近似，连击命中时取连击威力），并给出改进建议。

### 技能库页

- 全部职业技能一览：图标、职业、技能类型、威力、距离、半径、单体/群伤、复唱、充能、连击前置、变化技能、等级。
- 支持搜索（技能名/职业缩写/ID）与按列排序。

## 快速开始

### 方式一：一键运行

双击项目根目录的 `run.bat`。首次运行会自动创建 `.venv` 并安装依赖。

### 方式二：手动运行

```powershell
# 创建虚拟环境（Python 3.10）
python -m venv .venv

# 安装依赖
.venv\Scripts\python.exe -m pip install -r requirements.txt

# 启动
.venv\Scripts\python.exe main.py
```

依赖见 [requirements.txt](requirements.txt)：`PySide6-Essentials>=6.6`、`pynput>=1.7`。

> 注意：若系统未把 `python` 加入 PATH，请直接使用 `.venv\Scripts\python.exe`。

## 使用流程

1. 在顶部选择职业。
2. 进入「键位映射」页，把技能拖到热键栏并绑定按键（或使用自动分配）。
3. 进入「标准循环」页，添加技能步骤；期望时间会自动推算，也可手动调整顺序与循环参数。
4. 回到「训练」页设置统计时长与容差，点击开始；倒计时结束后按循环施放技能。
5. 训练结束自动跳转到「分析报告」，查看评分、时间轴与逐项差异。
6. 需要查询技能数据时使用「技能库」页。

> 全局监听提示：若游戏以管理员权限运行，本工具也需要以管理员身份启动，才能捕获游戏窗口内的按键；否则仍可记录本工具窗口内的按键。

## 游戏数据

### 数据文件

| 文件                    | 说明                                                            |
| --------------------- | ------------------------------------------------------------- |
| `data/jobs.json`      | 各职业的技能、热键栏、标准循环、循环长度、GCD 等可编辑数据                               |
| `data/game_data.json` | 从 XIVAPI v2 / 中文挖掘仓库抓取的游戏技能与状态数据（含复唱、积蓄次数、连击、变换、图标、距离/半径、威力等） |
| `data/settings.json`  | 当前职业、训练时长、判定容差、全局监听开关                                         |
| `assets/icons/*.png`  | 技能与状态图标                                                       |

`jobs.json` 顶层为 `{"jobs": [...]}`，单个职业主要字段：

```jsonc
{
  "id": "j38",
  "name": "舞者（ DNC ）",
  "abbrev": "DNC",
  "role": "",
  "gcd": 2.5,
  "loop": true,
  "cycle_length": 120.0,
  "notes": "循环说明",
  "skills": [
    {
      "name": "瀑泻",
      "recast": 2.5,
      "gcd": true,
      "gcd_time": 0,      // 0 表示使用职业默认 GCD
      "charges": 0,       // 积蓄次数（充能层数）
      "combo": "",
      "transform": ["喷泉"],
      "potency": 0,
      "combo_potency": 0
    }
  ],
  "rotation": [
    {"skill": "标准舞步", "offset": 0.0},
    {"skill": "蔷薇曲脚步", "offset": 1.5}
  ],
  "hotbar": ["瀑泻", "喷泉", ""],
  "hotbar_keys": ["1", "2", ""]
}
```

程序启动时会用 `game_data.json` 合并补全技能数据（复唱、充能、连击、变换、图标等），合并结果会写回 `jobs.json`。

### 重新抓取游戏数据

```powershell
# 抓取技能/状态数据并下载图标
.venv\Scripts\python.exe tools\fetch_game_data.py

# 仅补下载缺失图标
.venv\Scripts\python.exe tools\fetch_game_data.py --icons-only

# 忽略本地缓存，重新抓表
.venv\Scripts\python.exe tools\fetch_game_data.py --refresh
```

可选参数：`--status-only`（仅抓取状态数据）、`--workers N`（并发下载线程数，默认 8）。

抓取源：

- XIVAPI v2：`https://v2.xivapi.com/api`
- 中文数据挖掘：`thewakingsands/ff14-datamining-cn`

> 若「技能库」提示缺少数据，请先运行上述抓取脚本。

## 判定与评分说明

- 时间偏差在容差内记为 `OK`；早于/晚于容差记为 `偏早`/`偏晚`。
- 未按下的期望技能记为 `缺失`，标准循环之外的施放记为 `多余`，顺序错位记为 `顺序错误`。
- 按实际按键顺序推演冷却，统计冷却冲突、GCD 冲突与连击中断。
- 状态不足的施放（如伶俐不足仍使用剑舞）会被标记，并在威力统计中排除。
- 综合评分由顺序、时间、多余/缺失、冷却与连击等维度加权得到。

## 职业逻辑扩展

- 通用量谱规格位于 `app/gauge.py` 的 `SPECS`。
- 职业专属逻辑位于 `app/jobs/`，每个职业一个文件，继承 `JobLogic`。
- 新增职业：在 `app/jobs/` 下创建 `<职业缩写>.py`，实现 `JobLogic`（量谱、动态显示、施放校验、下一步高亮等），然后注册到 `app/jobs/__init__.py` 的 `_JOB_LOGICS`。

当前已实现的深度职业逻辑：**舞者（ DNC ）**（舞步序列、幻扇/伶俐、舞步期间替换与限制、剑舞高亮等）；

舞者标准循环参考**`艾欧泽亚 NGA玩家社区`**[从6.x出发的7.0舞者指南](https://bbs.nga.cn/read.php?tid=40837730)

其余职业使用通用量谱与数据驱动的连击/变换规则，**标准循环待补充完善**。

## 常见问题

**Q：全局监听没有反应？**\
A：确认训练设置中「全局监听」已开启；若游戏以管理员权限运行，请同样以管理员身份启动本工具。

**Q：技能没有图标 / 技能库为空？**\
A：运行 `tools/fetch_game_data.py` 抓取数据与图标；仅缺图标可加 `--icons-only`。

**Q：充能技能的层数在哪里看？**\
A：热键栏图标右下角显示当前可用层数；正在恢复的那一层会显示剩余秒数，全部充能就绪时不显示遮罩。

**Q：判定容差多少合适？**\
A：默认 500ms；网络/帧率稳定时可收紧到 300–400ms，追求严格对齐时可设为 200ms。
